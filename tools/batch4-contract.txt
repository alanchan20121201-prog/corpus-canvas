# Batch 4 shared contract (Corpus Canvas)

New i18n keys are listed at the bottom. Every language must translate ALL of them
by hand (no machine translation). A single screen must never mix languages.

## New public API on CC.graph (already implemented by the lead, use these only)

```js
CC.graph.presentItems() -> [{ id, title, body, note, tags: [], kind }]
  // ordered like the outline (roots first, depth-first); kind is '' | 'summary'

CC.graph.sceneForPrint() -> {
  bounds: { minX, minY, maxX, maxY, w, h },
  nodes: [{ id, x, y, w, h, title, fs, fill, accent, shape, bold, tags: [], kind }],
  edges: [{ id, type, label, color, uncertain, curved, d, arrow, mx, my }]
}
  // x/y are the node CENTER in world coordinates; d/arrow/mx/my are already
  // computed SVG path data in world coordinates.

CC.graph.currentMapId() -> string | null
```
