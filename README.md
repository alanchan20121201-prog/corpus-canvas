# Corpus Canvas · 资料画布

> 一份资料，多种画法。

一个本地优先的通用脑图工具：**资料是正本，图只是呈现方式**。节点连回同一份卡片数据，改一处即处处同步；同一批资料可以开多张图、用不同结构摆放。AI 只做辅助，所有产出先列草稿，逐条确认后才写入。

- 不收费、不订阅、不设账号、无遥测
- 资料只存本机，备份由你自己保管
- AI 由使用者自备服务地址与密钥，费用直接结算给服务商
- 支持 Windows 便携版（单 exe）

## 功能

**资料正本**
- 自由卡片：标题、正文、附注（可选）、标签、分类、来源追溯
- 变更记录、回退、自动/手动还原点
- 软删除与回收站、重复提示与合并、批量整理
- 资料检查：未入图、孤立节点、存疑连线、重复、断线

**绘图**
- 树状 / 组织图 / 自由连线三种结构，节点拖拽、连线类型与颜色、存疑标记
- 大纲视图与图双向同步
- 节点样式：形状、填充、图标、字号、加粗、超链接
- 区域框、复制节点、多选对齐、折叠、焦点模式、图模板
- 同一份资料多张图、图标签切换

**大规模**
- 视口虚拟化：只渲染当前画面与周边，其余资料保留不删
- 四档细节：完整 / 仅标题 / 色块 / 聚合模糊；状态栏显示「可见 / 总数」
- 布局与空间索引缓存，3 万节点约 0.3 秒建图

**检索**
- 全文检索（标题、正文、附注、标签），错字近似、简繁互通
- 标签 / 语言 / 时间 / 是否入图 / 待处理批注组合筛选
- 关系检索、结构检索、已存视图、结果成图/批量操作

**AI（自备密钥）**
- 起草 / 整理 / 简述 / 校阅，全部先出草稿
- 校阅只批注不改动，按把握程度分级；支持「仅本图」或「与全库比对」
- 兼容 OpenAI 风格接口，也支持 Ollama / LM Studio 本机模型
- 错误分类提示，不静默重试

**档案**
- 导入 XMind / OPML / Markdown，导入后统一为正本
- 一键备份为可读 JSON（`.wef`），可完整还原
- 导出 PNG / SVG / Markdown

## 7 种界面语言

简体中文、繁體中文、English、日本語、Español、Français、한국어。

- 默认「跟随系统」：使用电脑语言，匹配不到时用英文
- 全部界面文案与内置手册均为人工翻译，没有机器翻译回退

## 开发

```bash
npm install
npm start          # 开发运行
npm test           # 功能测试（node test/headless.js）
npm run test:ai    # AI 客户端契约测试
npm run build:win  # 打包 Windows 便携版
```

打包说明：本机若无法解压 `winCodeSign`（符号链接权限），使用

```bash
npx electron-builder --win portable -c.win.signAndEditExecutable=false
```

并在 `build/afterpack.js` 中用缓存里的 `rcedit` 写入图标与版本信息。

## 目录

```
electron/      主进程、IPC、AI 客户端
src/           渲染层（无框架，原生 JS + CSS）
  js/           store / layout / graph / views / search / ai / importer / help / i18n
  css/          设计系统与全部样式
test/          jsdom 功能测试、AI 契约测试、规模测试
build/         图标与打包钩子
tools/         构建期辅助（语言包机器翻译）
```

## 隐私

- 无账号、无遥测、无云同步
- 只有主动触发 AI 动作时，才会把所选范围文字发送到你填写的服务地址
- 密钥使用系统加密保存，不写日志、不进备份，可一键清除
