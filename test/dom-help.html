Corpus Canvas

使用手冊

每個功能都有一節說明。先看「五分鐘上手」，其余按需查。

五分鐘上手

這是一套「資料為正本、圖只是畫法」的工具。卡片存內容，圖存位置與連線；同一張卡片可以出現在多張圖裡，改一處，處處同步。

第一次打開

  1. 軟體會自動建一張圖和一個「中心主題」，光標已在標題上，直接改名即可。
  2. 按 Tab 或點「新增節點」加子節點；雙擊畫布空白也能加。
  3. 雙擊位置靠近某個節點（340px 內）會自動連成它的子節點；離得遠則是一個懸浮節點。按住 Shift 雙擊永遠是懸浮，不連線。
  4. 拖動節點時連線會實時跟隨；拖父節點會帶走整個分支。松手即儲存。
  5. 右下角可以縮放；工具欄「自動排布」會重新整理樹。

介面分區

  • 頂部：導航（首頁/圖/大綱/資料/檢索/檢查/紀錄/回收站）、搜尋、復原重做、AI、主題、語言、設定、幫助。
  • 第二行：圖標籤。點「+」新建圖，右鍵標籤可改名、複製、存模板、刪除。
  • 右側：屬性面板。選中節點后出現，改標題、正文、附註、標籤、分類、樣式。

圖與視圖

新建與切換

圖標籤欄的「+」新建一張圖；點標籤切換。每張圖有自己的擺位和連線，但卡片內容共用一份正本。

三種結構

  • 樹狀：從左到右的層級，最常用。
  • 組織圖：從上到下，適合匯報關係、目錄。
  • 自由連線：節點位置完全由你擺，適合概念圖。

切換結構時，已有擺位會被保留或轉換；「自動排布」會清掉手動偏移，回到自動布局。

焦點模式

選中節點后點工具欄的准星，只顯示它和相鄰一層，登出再點一次。適合在大圖裡看局部。

模板

把當前圖右鍵標籤「存為模板」，以后在圖標籤「+」旁邊或首頁從模板新建，會複製結構和卡片內容。

匯出

工具欄「…」裡有：匯出 PNG（整圖或當前視野）、匯出 SVG、匯出 Markdown 大綱。超過 2600 個節點時只匯出當前視野，避免卡死。

節點與卡片

新增

三種方式：工具欄「新增節點」、右鍵節點「新增子節點/同級」、雙擊畫布空白。靠近已有節點時會自動連線。

編輯

雙擊節點打開右側屬性面板。標題是圖上顯示的文字；正文是詳細內容；附註是可留空的補充，不影響節點本身。

標題為空時，圖上顯示正文第一行；正文也空則顯示灰色的「未命名」，不會是白板。

樣式

  • 形狀：圓角 / 方形 / 膠囊。
  • 填充：8 個色板；文字顏色會自動取對比色。
  • 圖標：填一個 emoji 或字符，顯示在標題左側。
  • 字號：小 / 中 / 大；B 切換加粗。
  • 鏈接：填 https://…，點右側按鈕用系統瀏覽器打開。

其他操作

  • 折疊：有子節點的右上角會顯示「+N」，點它收起/展開。
  • 複製：右鍵「複製節點」，或 Ctrl+D。
  • 對齊：多選后右鍵「左對齊 / 頂對齊」。
  • 刪除：Delete，進入回收站，可取回。
  • 區域框：選中多個節點，工具欄「…」→「區域框」，給一組節點加虛線范圍。

連線

手動拉線

  1. 點工具欄「拉線」，按鈕變亮。
  2. 點起點節點，再點終點節點。
  3. 在彈窗裡選類型（層次/同义/反义/因果/例證/對照/引用/自定），可寫說明、選顏色、勾「標為存疑」。

按 Esc 取消拉線。連線的說明只在 55% 以上縮放顯示。

編輯與刪除

雙擊連線打開同一個彈窗；右鍵連線可以標存疑或刪除。存疑連線在圖上用橙色虛線加「?」，會出現在「檢查」裡。

層次線與其他線

「層次」決定樹的父子關係（布局會用它）；同义、因果等只是關係，不影響樹結構，畫成帶箭頭的曲線。

大綱視圖

大綱與圖是同一份資料：這裡改標題、調層級，圖上立刻變；反過來也一樣。

  • 點標題直接改，回車提交。
  • Tab 降一級，Shift+Tab 升一級。
  • Enter 新增同級；行尾「+」新增子項。
  • 頂部可全部展開/收起。

大綱只顯示當前選中的那張圖。

資料庫

資料庫是正本：每張卡片可以自由填寫，不預設固定欄位。

字段

  • 標題、正文、附註（選用）、標籤、分類、來源。
  • 來源紀錄：手記 / 筆記 / 匯入 / AI 起草，帶時間，方便追溯。

整理

  • 篩選：全部 / 未入圖 / 已入圖，按標籤、語言（已移除介面入口）、時間過濾。
  • 勾選多張后底部出現批量條：加標籤、設分類、移入回收站。
  • 相近內容：屬性面板底部會提示相似卡片，可合併或忽略。合併會把標籤、附註、來源並過去，原卡片進回收站。

列表一次顯示 400 條，可用篩選或「載入更多」檢視后面的。

檢索

全文

一次搜標題、正文、附註、標籤。支援錯字近似和簡繁互通（「筆記」能搜到「筆記」）。

篩選

標籤、是否入圖、更新時間、是否有待處理批註，可組合。常用條件點「存為視圖」，下次一鍵套用。

關係

按連線類型列出全部關係，例如所有同义關係、所有存疑連線。

結構

找孤立節點、最深分支、重複節點、斷線（端點已刪除的連線）。

批量操作

勾選結果后可：由結果成圖、批量加標籤、批量連到某個節點。

檢查（原「體檢」）

檢查頁只做提示，不會改動資料。五類內容：

  • 未入圖的資料：卡片存在，但沒放進任何一張圖。可以一鍵為它們成圖。
  • 孤立節點：圖裡有節點沒有任何連線，通常是漏連了。
  • 存疑連線：拉線時勾了「存疑」，或 AI 校閱標出的不確定關係。
  • 重複內容：標題/正文高度相似，建議合併。
  • 斷線：連線的另一頭已在回收站或被刪除。

點條目可以直接跳到對應圖或卡片處理。

紀錄、快照與回收站

變更紀錄

每次結構性修改都會記一條。點「回退到此前」能把整份資料恢複到那一步之前，回退前會自動存一個還原點。

還原點

匯入、採用 AI、批量整理、合併前會自動留存；也可以手動「立即留存還原點」並命名。自動快照最多 12 個，手動快照單獨保留。

復原/重做

Ctrl+Z / Ctrl+Shift+Z，頂部也有按鈕。

回收站

刪除的卡片在這裡，可單張取回或全部取回；「徹底刪除」不可復原。連線會保留，取回后自動恢複。

匯入與備份

匯入

支援 XMind（.xmind）、OPML、Markdown / TXT 大綱。匯入后統一變成卡片與圖，不保留原圖檔案。可以選擇「轉成一張新圖」或「只加入資料庫」。

匯入后會顯示自檢報告：成功多少、跳過多少（空標題）、明細。匯入的卡片會紀錄來源，方便追溯。

備份

設定 → 一鍵備份，寫成一個可讀的 .wef（JSON）。還原時可「合併」或「覆蓋」；合併按 id 去重。

密鑰永遠不會寫進備份。換機器后需要重新填一次密鑰。

資料在哪

設定裡顯示資料路徑，可一鍵在資料夾中顯示。刪除軟體不會自動刪資料，請自行備份。

設定、隱私與費用

語言與主題

介面語言共 7 種：簡體中文、繁體中文、英語、日本語、西班牙語、法語、韓語。全部介面文案與內置手冊均為人工翻譯，切換后同一屏只出現一種語言。預設「跟隨系統」：用電腦語言，匹配不到就用英文。

主題有明亮、紙感、暗色、墨色。

AI 服務

自備服務地址、模型名與密鑰；也可以勾「使用本機模型」，不填密鑰直連 Ollama / LM Studio。詳見「AI 與 API」頁。

隱私

  • 無帳號、無遙測、無雲同步。
  • 只有你主動點 AI 動作時，才會把所選范圍的文字發到你填的地址。
  • 密鑰用系統加密儲存在本機，不寫日志、不進備份，可一鍵清除。

費用

軟體本身免費、無訂閱。AI 費用由你的服務商按用量收取。
